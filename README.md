# 지금 여기 하늘

내 위치(GPS)와 지금 시각으로 태양 고도를 계산해서, 그 순간의 하늘색이 화면 전체에 메시 그라데이션으로 번지는 모바일 웹이에요.

- 정적 페이지 한 장(`index.html`)이라 빌드가 없어요. 위치는 폰 안에서만 계산하고, 동네 이름을 붙일 때만 BigDataCloud 역지오코딩을 한 번 불러요.
- 위치 권한이 없으면 서울 기준으로 보여줘요.
- 시간대별 색은 `index.html`의 `SET`(해 지는 쪽), `RISE`(해 뜨는 쪽) 배열에서 고치면 돼요.
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열려요(`manifest.webmanifest`, `icons/`).
- Netlify에 연결하면 main에 푸시할 때마다 자동 배포돼요. GPS는 https에서만 동작해요.
